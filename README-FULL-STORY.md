# 네버랜드: 키퍼의 놀이공원 · 3D 전체 이야기

처음 만든 2D 프로토타입의 대사·퍼즐·이벤트·숨겨진 수치·엔딩을 3D 탐험에 연결했습니다. 구역 이동, 흔적 조사, 키퍼 대화, 기구 조작대와 최종 출구 접근은 직접 걸어서 진행합니다.

현재 맵은 선택한 레드·골드·에메랄드 그랜드 카니발입니다. 그랜드 엔트리가 맨 앞, 캡틴 훅이 중앙 섬, 회전목마·관람차·거울 미로·찻잔이 네 방향에 있습니다. `전체 풍경` 버튼으로 공원을 내려다보고, `걷기로 돌아가기`로 보행을 재개합니다. 상세 구현 내역은 `CARNIVAL-IMPLEMENTATION.md`를 참고하세요.

각 기구 입구에서 E를 누르면 별도 내부 공간으로 이동합니다. 갑판·승강장·목마 홀·거울 회랑·찻잔 안을 WASD로 걸어 다닐 수 있습니다. 좌석 가까이에서 E로 탑승하고, 다시 E 또는 `기구 조작`으로 원본 퍼즐을 풉니다. 성공하면 실제 탑승 시점으로 기구가 움직이고, 탑승이 끝난 뒤 정상 성공 보상이 반영됩니다. Q 또는 `일어나기`로 내리고 `공원으로 돌아가기`로 입구에 복귀합니다. 이동 중에는 하차와 복귀가 잠깁니다.

거울 미로는 좌석 대신 실제 벽 사이를 걸어 빛 장치에 도달하고, 퍼즐을 푼 뒤 반대편 빛의 출구까지 직접 이동해야 성공합니다. `지도`는 내부에서는 해당 공간의 벽·좌석·장치·현재 위치를 보여줍니다. 상세 내용은 `RIDE-INTERIORS.md`에 있습니다.

## 실행

`START.cmd` 또는 `node server.cjs` 실행 후 `http://127.0.0.1:8773`으로 접속합니다. 외부 패키지와 인터넷 연결이 필요하지 않습니다. 이미 실행 중인 서버는 해당 포트 주소를 이용합니다.

`play-full-story.html`은 이미지와 코드가 포함된 단일 파일입니다. 더블 클릭으로 오프라인 실행할 수 있습니다. `node package-full-story.cjs`로 다시 만듭니다. 기존 `play.html`과 `package.cjs`는 이전 탐험판입니다.

## 플레이

이름·성별·놀이기구 성향을 정하고 프롤로그를 읽으세요. WASD로 선실 문을 지나면 키퍼의 첫 만남이 시작됩니다. 오른쪽 캡틴 훅 조작대에 다가가 E를 눌러 첫 레버를 조작합니다. 첫 사고와 실체 컷씬 이후 공원 전체를 걸어서 탐험할 수 있습니다.

- WASD 이동, Shift 빠르게 걷기, 마우스 또는 드래그로 보기, 방향키 좌우 회전, E 상호작용.
- 지도는 실제 3D 좌표를 기준으로 현재 위치(붉은 점)와 바라보는 방향(화살표)을 표시합니다. 선택 기능은 없으며 실제 이동은 걷기로 진행합니다. 데크에서는 중앙의 열린 통로를 이용합니다.
- 각 구역에서 키퍼, 조작대, 금빛 흔적을 찾으세요. 단서는 최초 조사 때만 점수가 쌓입니다.
- 대화는 성향에 따른 두 답변 중 하나를 고릅니다. 세 번 대화하면 키퍼가 탑승을 권합니다.
- 다섯 퍼즐: 안전 레버, 달·별·태양 정렬, 랜덤 4음 악보, 3×3 거울 빛길, 보라색 찻잔과 안전 속도.
- 막히면 도움 수락, 다시 시도, 경고를 무시한 강행을 선택할 수 있습니다.
- 새 구역 첫 이동에는 원본과 같은 확률로 퍼레이드 또는 주사위 이벤트가 발생합니다.
- 조건을 만족하면 기구 구역 하나에 빛기둥·원형 문양·금빛 입자가 모여 출구가 나타나고 지도에도 빛나는 문으로 표시됩니다. 키퍼가 문 앞을 막고 있습니다. 직접 걸어가 E를 누르면 플레이어가 떠나지 않기를 바라는 키퍼와 대치한 뒤 최종 선택으로 이어집니다.
- 다섯 엔딩과 성별별 엔딩 그림, 엔딩 기록을 유지합니다. 진행 자동 저장은 없고 엔딩 기록만 브라우저에 남습니다.

## 원본과 검증

`story-core.js`는 승인된 2D 배포본의 이야기 스크립트 그대로입니다. `story-3d.js`는 이동·접근 연결, `world.js`는 보행·충돌·접근, `carnival-scene.js`는 재질·조명·실제 3D 모델 렌더링을 담당합니다. `carnival-layout.js`의 공통 좌표를 지도·상호작용·렌더러가 함께 사용합니다. Three.js는 `vendor/`에 동봉되어 인터넷이 필요 없으며 라이선스는 `vendor/THREE-LICENSE.txt`입니다.

`original-2d/index.html`은 내용 대조용 원본 스냅샷입니다. 실제 게임은 루트 `index.html` 또는 `play-full-story.html`을 실행합니다. 기존 2D 원본과 공개 사이트는 변경하지 않았습니다.

새 버전의 검증 명령은 `node verify-full-story.cjs`입니다. 기존 `verify.cjs`는 이전 탐험판 검증입니다. 내역은 `QA-FULL-STORY.md`, 내용 대조는 `CONTENT_PARITY.md`에 있습니다.
