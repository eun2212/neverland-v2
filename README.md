# 네버랜드 놀이공원 · 버전 2

기존 2D 게임과 별개로 만든, 직접 걸어 다니는 1인칭 WebGL 탐험 버전입니다. 공개 배포는 하지 않았습니다.

## 실행

`START.cmd`를 실행한 뒤 브라우저에서 http://127.0.0.1:8773 을 여세요. Node.js가 있으면 로컬 서버를 실행하며, 서버 창을 닫으면 종료됩니다. 명령으로 실행할 때는 이 폴더에서 `node server.cjs`를 사용하세요. 외부 라이브러리 설치와 인터넷 연결은 필요하지 않습니다. WebGL을 지원하는 최신 데스크톱 브라우저를 권장합니다.

Node.js가 없을 때는 index.html을 직접 엽니다. 브라우저의 로컬 파일 보안 정책 때문에 키퍼 텍스처가 차단되면 로컬 HTTP 서버 실행이 필요합니다.

## 플레이

- 눈을 뜨다 → WASD로 문 통과 → 데크 끝 → 키퍼의 첫 대사.
- 키퍼에게 다가가 E → 안내 → 오른쪽 붉은 레버에 다가가 E.
- 첫 사고 이후 다시 깨어남 → 데크 북쪽 금빛 입구를 밟으면 놀이기구 맵으로 자동 이동 → 각 기구의 조작대에서 E.
- 놀이기구 맵에서 뒤쪽 금빛 입구로 걸어가면 데크로 복귀합니다. 탐험 기록은 유지됩니다.
- 다섯 기구의 탐험 기록을 모으면 키퍼에게 돌아와 마지막 대사를 들을 수 있습니다.
- 마우스 클릭 후 시점 이동, Esc로 해제. 잠금이 지원되지 않으면 드래그. 방향키 좌우로도 시점을 돌릴 수 있습니다.
- Shift로 빠르게 걷기. 휴대전화에서는 화면 아래 이동 버튼과 드래그 사용.
- 음악은 시작 버튼을 누른 뒤 브라우저에서 합성합니다. 오른쪽 위 음소거 제공.

## 범위

깨어남·데크·공원 발견·첫 만남·고정 사고·다섯 기구의 직접 접근 및 작동을 체험하는 독립 탐험판입니다. 기존 2D 버전의 모든 퍼즐, 성향·관계 수치, 이벤트와 다섯 엔딩을 이식한 완결판은 아닙니다. 이동은 실제 3D 좌표와 충돌 판정을 사용하며, 빛의 입구 구역에서 데크와 놀이기구 맵 사이를 자동 이동합니다. 기구 탑승 시점 대신 조작 후 움직임을 주변에서 관찰합니다.

기존 세계관과 확정 키퍼 디자인을 참고했습니다. 키퍼는 사용자 후속 요청에 따라 기존 확정 상반신 그림을 사용합니다. 대화 중에는 화면 중앙 앞쪽에 상반신을 크게 표시하고, 대화를 마치면 3D 공간에 전신 빌보드로 표시합니다. 생성 프롬프트는 ASSET_PROMPT.txt에 기록했습니다. 외부 이미지·음원·폰트·CDN을 요청하지 않습니다. 게임 내용과 그림의 권리는 원작자에게 있습니다. 링크 공유 허용, 무단 수정·복제·재배포 금지.

## 파일

- index.html / style.css / game.js: 게임 소스
- assets/keeper-upper.webp: 최종 상반신 키퍼 / keeper-full.png: 탐험 중 전신 빌보드
- server.cjs / START.cmd: 로컬 실행
- verify.cjs: 렌더링 호출·이동·충돌·이야기·기구·음소거의 회귀 검증
- QA.md: 실제 검증 결과
