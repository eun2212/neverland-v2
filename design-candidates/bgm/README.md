# BGM 감상용 시안

메인·캡틴 훅·관람차·회전목마·거울 미로·찻잔·출구 대치·흑백 맵에 각 3곡, 총 24곡입니다. index.html에서 A/B/C를 비교하고 선택할 수 있습니다. 자동 재생하지 않으며 재생 중 다른 곡을 누르면 이전 곡을 멈춥니다. 오디오는 반복 재생합니다. 선택은 브라우저를 닫으면 유지되지 않으므로 결과를 복사해 전달합니다.

render.cjs로 직접 작곡·합성한 오리지널 인스트루멘털 시안입니다. 외부 음악 모델이나 샘플 음원을 사용하지 않았습니다. 오르골·첼레스타·피아노·목관·유원지 오르간·유리종·현악·패드를 모사한 합성 음색이며 전문 연주 녹음이나 최종 마스터가 아닙니다. 세부 편성·템포·설명은 manifest.json에 있습니다. 22,050 Hz, 스테레오 PCM 16-bit WAV. 약 20~55초. 순환 잔향을 사용해 반복 재생을 고려했습니다.

이번 변경은 디자인 후보 보관만 포함합니다. 실제 게임의 BGM과 장면 전환은 수정하지 않았습니다. 선택 후 해당 곡의 확장·편곡과 게임 적용을 진행합니다.

재생성: node design-candidates/bgm/render.cjs. 생성기는 같은 폴더와 프로젝트 옆 outputs/bgm에 WAV·비교 페이지·명세를 저장합니다.
